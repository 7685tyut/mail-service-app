# Mail Client App - Почтовый клиент для Windows

## Описание

**Mail Client App** - это красивое Windows-приложение на C# с WPF для работы с почтой любых доменов. Приложение поддерживает:

- ✅ Работу с несколькими почтовыми аккаунтами (Gmail, Yandex, Mail.ru, Outlook и др.)
- ✅ Получение и отправку писем через IMAP/SMTP
- ✅ Подробный журнал операций (логирование)
- ✅ Поддержку вложений
- ✅ Красивый современный интерфейс на Material Design
- ✅ Синхронизацию почты
- ✅ Просмотр папок IMAP
- ✅ Ответ и пересылку писем

## Установка и запуск

### ⚠️ ВАЖНО: Требуется .NET 6.0 SDK

Если вы видите ошибку `"dotnet" не является внутренней или внешней командой`, следуйте инструкциям в файле **[INSTALL.md](INSTALL.md)**

### 1. Установка .NET 6.0 SDK

**Способ 1 (Рекомендуется):**
- Запустите `install-dotnet.ps1` из PowerShell от имени администратора
- Или запустите `install-dotnet.bat` из командной строки от имени администратора

**Способ 2:**
- Скачайте и установите вручную: [https://dotnet.microsoft.com/download/dotnet/6.0](https://dotnet.microsoft.com/download/dotnet/6.0)

**Способ 3:**
- Установите Visual Studio 2022, откройте `MailClientApp.sln` и следуйте подсказкам

### 2. Проверка установки

```bash
dotnet --version
```
Должно вывести: `6.0.400` или выше

### 3. Клонирование репозитория

```bash
git clone https://github.com/7685tyut/mail-service-app.git
cd mail-service-app/MailClientApp
```

### 4. Восстановление NuGet пакетов

```bash
dotnet restore
```

### 5. Сборка проекта

```bash
dotnet build
```

### 6. Запуск приложения

```bash
dotnet run
```

## Настройка аккаунтов

### Добавление нового аккаунта

1. Нажмите кнопку "Добавить аккаунт" в левой панели
2. Выберите почтовый сервис из списка (Gmail, Yandex, Mail.ru, Outlook) или "Custom" для ручной настройки
3. Заполните поля:
   - **Имя аккаунта**: Название для отображения
   - **Email адрес**: Ваш email
   - **SMTP сервер**: Сервер исходящей почты
   - **SMTP порт**: Порт SMTP (обычно 587 или 465)
   - **IMAP сервер**: Сервер входящей почты
   - **IMAP порт**: Порт IMAP (обычно 993 или 143)
   - **Имя пользователя**: Логин для авторизации
   - **Пароль**: Пароль от почтового ящика
4. Нажмите "Сохранить"

### Настройки для популярных сервисов

| Сервис | SMTP Сервер | SMTP Порт | IMAP Сервер | IMAP Порт |
|--------|-------------|-----------|-------------|-----------|
| Gmail | smtp.gmail.com | 587 | imap.gmail.com | 993 |
| Yandex | smtp.yandex.ru | 587 | imap.yandex.ru | 993 |
| Mail.ru | smtp.mail.ru | 587 | imap.mail.ru | 993 |
| Outlook | smtp-mail.outlook.com | 587 | outlook.office365.com | 993 |

### Примечания по безопасности

- Для Gmail может потребоваться включить "Небезопасные приложения" или использовать App Password
- Для Yandex может потребоваться включить IMAP в настройках почтового ящика
- Убедитесь, что SSL включен для всех соединений

## Функции приложения

### Работа с почтой

- **Получение писем**: Нажмите "Получить" для загрузки новых писем
- **Синхронизация**: Нажмите "Синхронизировать" для обновления всех папок
- **Отправка письма**: Заполните поля "Кому", "Тема", "Текст" и нажмите "Отправить"
- **Ответ на письмо**: Выберите письмо и нажмите "Ответить"
- **Пересылка письма**: Выберите письмо и нажмите "Переслать"
- **Удаление письма**: Выберите письмо и нажмите "Удалить"

### Журнал операций

Все действия приложения записываются в журнал:
- Отправка писем
- Получение писем
- Ошибки подключения
- Системные события

Журнал отображается в нижней части окна и сохраняется в файле:
`%APPDATA%\MailClientApp\Logs\mail-client-{date}.log`

### Поиск писем

Используйте поле поиска для фильтрации писем по:
- Отправителю
- Получателю
- Теме
- Содержимому

## Решение проблем

### Частые проблемы

1. **Ошибка подключения к Gmail**
   - Включите "Небезопасные приложения" в настройках Google
   - Используйте App Password вместо обычного пароля
   - Убедитесь, что IMAP включен в настройках Gmail

2. **Ошибка подключения к Yandex**
   - Включите IMAP в настройках почтового ящика
   - Проверьте, что пароль введен правильно

3. **Письма не загружаются**
   - Проверьте настройки IMAP сервера и порта
   - Убедитесь, что SSL включен
   - Проверьте подключение к интернету

4. **Письма не отправляются**
   - Проверьте настройки SMTP сервера и порта
   - Убедитесь, что аутентификация включена
   - Проверьте, что email отправителя совпадает с аккаунтом

### Просмотр логов

Логи сохраняются в:
- `%APPDATA%\MailClientApp\Logs\`

Вы также можете просмотреть последние логи в приложении, нажав "Обновить" в панели журнала.
