# 📥 Руководство по установке Mail Client App

## 🔴 Ошибка: "dotnet" не является внутренней или внешней командой

Эта ошибка означает, что у вас не установлен **.NET SDK** на компьютере. Вот как это исправить:

---

## 🎯 Способ 1: Автоматическая установка (Рекомендуется)

### Вариант A: Используя PowerShell (Лучший способ)

1. **Откройте PowerShell от имени администратора**
   - Нажмите `Win + X` и выберите "Windows PowerShell (Администратор)"
   - Или найдите PowerShell в меню Пуск, щелкните правой кнопкой и выберите "Запуск от имени администратора"

2. **Перейдите в папку с приложением**
   ```powershell
   cd "C:\Users\Assets\Desktop\mail-service-app-main"
   ```

3. **Запустите скрипт установки**
   ```powershell
   .\install-dotnet.ps1
   ```

4. **Следуйте инструкциям на экране**
   - Скрипт автоматически скачает и установит .NET 6.0 SDK
   - После установки приложение запустится автоматически

### Вариант B: Используя командную строку (CMD)

1. **Откройте командную строку от имени администратора**
   - Нажмите `Win + R`, введите `cmd`, нажмите `Ctrl + Shift + Enter`

2. **Перейдите в папку с приложением**
   ```cmd
   cd "C:\Users\Assets\Desktop\mail-service-app-main"
   ```

3. **Запустите bat-файл**
   ```cmd
   install-dotnet.bat
   ```

4. **Следуйте инструкциям на экране**

## 🎯 Способ 2: Ручная установка .NET SDK

### Шаг 1: Скачайте .NET 6.0 SDK

1. Перейдите на сайт: [https://dotnet.microsoft.com/download/dotnet/6.0](https://dotnet.microsoft.com/download/dotnet/6.0)

2. Выберите **SDK** (не Runtime!)

3. Скачайте **x64 установщик** для Windows

4. Запустите скачанный файл и следуйте инструкциям установщика

### Шаг 2: Проверьте установку

1. Откройте новую командную строку
2. Введите:
   ```cmd
   dotnet --version
   ```
3. Вы должны увидеть версию, например: `6.0.400`

### Шаг 3: Запустите приложение

1. Перейдите в папку с приложением:
   ```cmd
   cd "C:\Users\Assets\Desktop\mail-service-app-main\MailClientApp"
   ```

2. Восстановите пакеты NuGet:
   ```cmd
   dotnet restore
   ```

3. Соберите проект:
   ```cmd
   dotnet build
   ```

4. Запустите приложение:
   ```cmd
   dotnet run
   ```

## 📋 Проверка установки

Чтобы убедиться, что .NET SDK установлен правильно, выполните:

```cmd
dotnet --list-sdks
```

Вы должны увидеть что-то вроде:
```
6.0.400 [C:\Program Files\dotnet\sdk]
```

## ❓ Частые вопросы

### Q: Почему я не могу запустить `dotnet` команды?
**A:** У вас не установлен .NET SDK. Используйте один из способов выше для установки.

### Q: Я установил .NET, но команды все равно не работают
**A:** 
- Закройте и откройте командную строку заново
- Убедитесь, что вы установили **SDK**, а не **Runtime**
- Проверьте, что путь к dotnet добавлен в переменную PATH

### Q: Какую версию .NET нужно установить?
**A:** Нужно установить **.NET 6.0 SDK** (не Runtime!)

### Q: Можно ли запустить приложение без установки .NET SDK?
**A:** Нет, приложение требует .NET 6.0 SDK для сборки и запуска.

## 🔧 Решение проблем

### Проблема: "dotnet" не распознается после установки

1. Проверьте, что вы установили **SDK**, а не **Runtime**
2. Перезагрузите компьютер
3. Проверьте переменную PATH:
   ```cmd
   echo %PATH%
   ```
   Вы должны увидеть путь к dotnet, например: `C:\Program Files\dotnet`

### Проблема: Ошибка при скачивании установщика

1. Проверьте подключение к интернету
2. Попробуйте скачать установщик вручную с [официального сайта](https://dotnet.microsoft.com/download/dotnet/6.0)
3. Запустите установщик вручную

### Проблема: Не хватает прав для установки

1. Запустите командную строку или PowerShell **от имени администратора**
2. Попробуйте установить .NET SDK вручную через установщик

После успешной установки .NET SDK вы можете:

   ```cmd
   cd MailClientApp
   ```

   ```cmd

   ```

3. **Опубликовать приложение:**
   ```cmd
   dotnet publish -c Release -r win-x64 --self-contained true
   ```
