================================================================================
                    MAIL CLIENT APP - БЫСТРЫЙ СТАРТ
================================================================================

ВАЖНО: Для работы приложения требуется .NET 6.0 SDK

================================================================================
ШАГ 1: УСТАНОВИТЕ .NET 6.0 SDK
================================================================================

Вариант 1 (Рекомендуется):
----------------------------
1. Откройте PowerShell от имени администратора
2. Выполните: .\install-dotnet.ps1

Вариант 2:
----------
1. Скачайте .NET 6.0 SDK с сайта:
   https://dotnet.microsoft.com/download/dotnet/6.0
2. Установите скачанный файл

Вариант 3:
----------
1. Установите Visual Studio 2022 Community
2. Откройте MailClientApp.sln
3. Visual Studio предложит установить .NET 6.0 SDK

================================================================================
ШАГ 2: ПРОВЕРЬТЕ УСТАНОВКУ
================================================================================

Откройте новую командную строку и выполните:
    dotnet --version

Вы должны увидеть: 6.0.400 (или выше)

================================================================================
ШАГ 3: ЗАПУСТИТЕ ПРИЛОЖЕНИЕ
================================================================================

1. Перейдите в папку MailClientApp:
   cd MailClientApp

2. Восстановите пакеты NuGet:
   dotnet restore

3. Соберите проект:
   dotnet build

4. Запустите приложение:
   dotnet run

ИЛИ просто:
   dotnet run

================================================================================
КРАТКАЯ ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ
================================================================================

1. ДОБАВЬТЕ АККАУНТ:
   - Нажмите "Добавить аккаунт" в левой панели
   - Выберите почтовый сервис (Gmail, Yandex, Mail.ru, Outlook)
   - Заполните данные для подключения
   - Нажмите "Сохранить"

2. ПОЛУЧИТЕ ПИСЬМА:
   - Выберите аккаунт из списка
   - Нажмите "Получить" на панели инструментов

3. ОТПРАВЬТЕ ПИСЬМО:
   - Заполните поля "Кому", "Тема", "Текст"
   - Нажмите "Отправить"

4. ДРУГИЕ ФУНКЦИИ:
   - Синхронизация: Обновить все папки
   - Ответить: Ответить на выбранное письмо
   - Переслать: Переслать выбранное письмо
   - Удалить: Удалить выбранное письмо

================================================================================
РЕШЕНИЕ ПРОБЛЕМ
================================================================================

Проблема: "dotnet" не является командой
Решение: Установите .NET 6.0 SDK (см. Шаг 1)

Проблема: Ошибка подключения к Gmail
Решение: Включите IMAP в настройках Gmail и используйте App Password

Проблема: Ошибка подключения к Yandex
Решение: Включите IMAP в настройках почтового ящика Yandex
